# 미해결 기록

## 미해결 과업 없음
이번 미션에서 프롬프트를 고쳐도 해결하지 못한 과업은 없었다. 성공한 시도는 이 문서에 적지 않는다.

## 향후 확장 계획 (아직 시도하지 않음, 미해결 과업이 아님)
아래는 이후에 추가할 기능이다. 시도한 프롬프트와 막힌 이유가 없어서 미해결 과업으로 세지 않는다.

1. 코드 변경 설명 추가: 입력에 코드 변경(diff 등)이 있으면, 코드가 어떻게 수정되었는지와 기존에는 어떤 문제가 있어 수정했는지를 변경 기록에 함께 적도록 프롬프트를 확장한다.
2. GitHub나 Notion에 MCP를 연결해 변경 기록이 자동으로 기록되고 관리되도록 한다. 이번 미션의 범위 밖이라 계획으로만 둔다.
